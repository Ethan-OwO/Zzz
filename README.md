# Zzz

Zzz 是一個在瀏覽器裡跑的免費睡眠聲音監測網站：睡前把手機插著充電、開著網頁，它會學習背景噪音，只記錄超出背景的聲音，醒來後在本機分析。

**零資料收集。** 所有錄音與分析都只在你的裝置上進行，網站不上傳任何資料、不使用分析工具、不載入任何外部資源。

## 使用方式

1. 睡前把手機插上充電，打開網站按「開始」並允許麥克風。
2. **睡前校準(約 40 秒)**:先保持安靜 30 秒讓 Zzz 學習房間的背景聲音，再用平常講話的音量說一句話。Zzz 會依這兩個音量決定「多大聲才算事件」,結果頁可以用 − / + 微調。
3. 選擇模式：
   - **正式**:打呼只記錄時段與次數，不錄音;翻身、說夢話等其他聲音才會錄下來。
   - **測試**:打呼也錄音，觸發門檻再降低一點，會多錄一些，方便早上確認判斷準不準。
4. 按「開始睡覺」後畫面會全黑，可以鎖屏。點一下螢幕顯示狀態，長按 2 秒停止。
5. 早上停止後會看到事件列表：每個聲音事件可以播放，打呼顯示成時段。可以下載除錯用的 JSON(不含錄音)。
6. 一次只保存一晚：要開始新的一晚，先長按刪除上一晚的紀錄。
7. 如果網頁中途被關掉或重新整理，下次打開會詢問要「繼續監測」或「結束並查看」。

所有錄音與紀錄只存在手機瀏覽器的 IndexedDB,不會上傳。

## 手機放哪裡(動作感測，選配)

首頁可以選「放床上」或「放床頭櫃」,每次打開網頁都預設床頭櫃，不會記住上次的選擇。

- **放床頭櫃**:只用聲音。
- **放床上**:另外用加速度計記錄翻身等動作。iPhone 會在點「放床上」時詢問「動作與方向」權限;不允許的話今晚只用聲音，錄音照常。
- 動作量每 30 秒算一筆(actigraphy):取加速度的大小、減掉緩慢變化的重力基準，記錄這 30 秒內動了幾秒、動得多大。原始加速度不會保存。
- 這些紀錄存在瀏覽器的另一個 IndexedDB 資料庫(`zzz-motion`),會一起放進「下載全部 JSON」,也會被「刪除全部」一起清除。

## 開發

需要 Node 22.12 以上(建議 24)與 pnpm 10。

```bash
pnpm install   # 安裝依賴
pnpm dev       # 啟動開發伺服器
pnpm build     # 型別檢查 + 產生 dist/
pnpm check     # build、單元測試，再用 Chromium 加上合成麥克風音檔驗證 CSP 與整個錄音流程(約 3 分鐘)
```

- `pnpm dev` 使用自簽憑證的 HTTPS(麥克風等 API 只在安全連線下可用)。要用手機測試，手機需與電腦在同一個 Wi-Fi,開啟終端機顯示的 `https://<區網 IP>:5173/`;瀏覽器會警告憑證不受信任，選擇繼續即可。
- 第一次在自己電腦跑 `pnpm check` 前，先執行一次 `pnpm exec playwright install chromium`。

## 部署

使用 Cloudflare Pages 連結此 repo:

- `main` 分支為正式站，其他分支會自動產生預覽網址。
- Build command:`pnpm build`
- Build output directory:`dist`

## 自己驗證隱私

網站的回應標頭帶有嚴格的 `Content-Security-Policy`,其中 `connect-src 'self'` 代表頁面只能連回自己的網域，瀏覽器會擋下任何往外送資料的請求。

- 打開瀏覽器 DevTools → Network,點選主文件，查看回應標頭的 `Content-Security-Policy`。
- 或在終端機執行 `curl -sI <網址>`。
